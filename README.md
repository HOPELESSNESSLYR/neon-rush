# NEON RUSH · 霓虹冲刺

在无尽霓虹网格里狂奔的 3D 无尽跑酷。躲开障碍、收集金币、积满能量后启动超载，直接撞碎前方一切。

纯前端、单文件。打开 `index.html` 即可游玩，不需要构建，也不需要后端。

## 怎么玩

三条赛道向前延伸，速度会随时间加快。每排障碍至少留一条安全道，看准再变道。

| 障碍 | 外观 | 应对 |
| --- | --- | --- |
| 墙 | 粉色，标有左右箭头 | 换到其他赛道 |
| 低障 | 金色，标有上箭头 | 跳跃越过 |
| 高障 | 青色，标有下箭头 | 滑铲钻过 |

- **金币**：沿安全道排列。普通状态下每枚 +10 分、+7 能量；超载中每枚 +20 分、+3 能量，并会被吸向角色。
- **超载**：能量满 100 后按 `Shift`（或右下角按钮）启动，持续约 5 秒。期间速度约 ×1.32，路程得分翻倍，撞上障碍会击碎并 +40 分，而不是结束本局。
- **得分**：随奔跑距离持续增长（超载期间翻倍），再加上金币和击碎障碍。结算时显示得分、金币、距离，并与历史最高分比较。
- **暂停**：按 `P` 或 `Esc`，或切到其他标签页时自动暂停。

最高分保存在本机 `localStorage`（键名 `neonrush.best`），音效开关保存在 `neonrush.sound`。

## 操作

### 键盘

| 按键 | 作用 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 变道 |
| `Space` / `W` / `↑` | 跳跃 |
| `S` / `↓` | 滑铲 |
| `Shift` / `F` | 超载（能量满时） |
| `P` / `Esc` | 暂停 / 继续 |
| `M` | 开关音效 |
| `Space` / `Enter` / `R` | 在开始或结算界面开局 |

### 触控

- 左右滑动：变道
- 上滑或轻点屏幕：跳跃
- 下滑：滑铲
- 右下角按钮：超载

## 运行

用浏览器直接打开 `index.html`。

3D 引擎优先加载同目录的 `libs/three.min.js`（Three.js r128）。本地文件缺失时，会回退到 jsDelivr 上的同版本脚本，这时需要联网。

也可用任意静态服务器，例如：

```bash
npx serve .
```

然后访问提示的本地地址。

## 技术

- 单页：HTML + CSS + 原生 JavaScript，逻辑全部在 `index.html`
- 渲染：Three.js r128，WebGL，ACES 色调映射，指数雾
- 场景：三车道网格、发光护栏、柱廊、星空与粒子拖尾
- 音效：Web Audio API 现场合成，无音频文件
- 适配：桌面键鼠与触控；窗口缩放时重设画布与像素比（上限 2）
