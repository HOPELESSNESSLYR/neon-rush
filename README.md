# NEON RUSH · 霓虹冲刺

在无尽霓虹网格里狂奔的 3D 无尽跑酷。躲开障碍、收集金币、积满能量后启动超载，直接撞碎前方一切。

纯前端、单文件。打开 `index.html` 即可游玩，不需要构建，也不需要后端。

## 怎么玩

三条赛道向前延伸，速度会随时间加快。每排障碍至少留一条安全道，看准再变道。

| 障碍 | 外观 | 应对 |
| --- | --- | --- |
| 墙 | 粉色，标有左右箭头 | 换到其他赛道 |
| 低障 | 金色，标有上箭头 | 跳跃越过 |
| 高障 | 青色，标有下箭头 | 滑铲钻过 |

- **金币**：沿安全道排列。普通状态下每枚 +10 分、+7 能量；超载中每枚 +20 分、+3 能量，并会被吸向角色。
- **超载**：能量满 100 后按 `Shift`（或右下角按钮）启动，持续约 5 秒。期间速度约 ×1.32，路程得分翻倍，撞上障碍会击碎并 +40 分，而不是结束本局。
- **得分**：随奔跑距离持续增长（超载期间翻倍），再加上金币和击碎障碍。结算时显示得分、金币、距离，并与历史最高分比较。
- **暂停**：按 `P` 或 `Esc`，或切到其他标签页时自动暂停。

最高分保存在本机 `localStorage`（键名 `neonrush.best`），音效开关保存在 `neonrush.sound`。

## 操作

### 键盘

| 按键 | 作用 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 变道 |
| `Space` / `W` / `↑` | 跳跃 |
| `S` / `↓` | 滑铲 |
| `Shift` / `F` | 超载（能量满时） |
| `P` / `Esc` | 暂停 / 继续 |
| `M` | 开关音效 |
| `Space` / `Enter` / `R` | 在开始或结算界面开局 |

### 触控

- 左右滑动：变道
- 上滑或轻点屏幕：跳跃
- 下滑：滑铲
- 右下角按钮：超载

## 运行

用浏览器直接打开 `index.html`。

3D 引擎优先加载同目录的 `libs/three.min.js`（Three.js r128）。本地文件缺失时，会回退到 jsDelivr 上的同版本脚本，这时需要联网。

也可用任意静态服务器，例如：

```bash
npx serve .
```

然后访问提示的本地地址。

## 具身智能体

没有实体机器人时，这局跑酷就是一具虚拟身体：三条车道、跳跃、滑铲和超载都受游戏规则约束，撞上就会结束。外部程序通过页面上的 `window.__NEON` 读取状态并单步推进，不改分数、不改坐标、不删障碍。

障碍从远处生成，`z` 为负，向角色（`z ≈ 0`）移动，越接近 0 越近。碰撞发生在 `|z| < 1.15`。

| 接口 | 作用 |
| --- | --- |
| `state()` | 车道、高度、是否着地、滑铲剩余时间、速度、能量、超载剩余时间，以及障碍 `{ t, l, z }` |
| `moveLane(dir)` | 变道。`dir` 为 `-1` / `1`，也可一次跨两条 |
| `jump()` / `slide()` / `boost()` | 跳跃、滑铲、超载。起跳后未落地时，后两个调用无效 |
| `setManual(true)` | 画面继续画，逻辑改由外部推进 |
| `advance(秒)` | 按固定步长更新世界 |
| `start()` | 重新开一局 |

`state().obs` 里会有很远的障碍。示例智能体只保留 `-28 < z < -0.3`，大约前方一秒以内，更远的等于还没看见。

规则写在 `examples/rule-agent.js`。打开游戏，等标题画面出现，把该文件贴进浏览器控制台：

```javascript
runEmbodiedAgent()
```

默认按真实时间最多跑 90 秒。快速跑完 30 秒可以写：

```javascript
runEmbodiedAgent({ realtime: false, seconds: 30 })
```

每一步都是「看 → 决定 → 动 → 推进 1/30 秒」：

- 自己车道上最近的是低障，到达时间小于 0.42 秒：`jump()`
- 最近的是高障，到达时间小于 0.48 秒：`slide()`
- 最近的是墙，到达时间小于 1 秒：换到一条没有墙、也不必横穿近处障碍的车道
- 无路可走且能量满 100：`boost()`

跳跃会把身体留在空中大约 0.7 秒。低障后面如果紧跟着墙，这一跳躲得开低障，却躲不开墙。因此同一套规则有的局能跑完三十多秒，有的局会撞毁。控制台会打印得分、金币和最后几次决策。

换一套策略时，只替换 `decide()`。`perceive()`、`act()` 和 `advance()` 不用改。

## 技术

- 单页：HTML + CSS + 原生 JavaScript，逻辑全部在 `index.html`
- 渲染：Three.js r128，WebGL，ACES 色调映射，指数雾
- 场景：三车道网格、发光护栏、柱廊、星空与粒子拖尾
- 音效：Web Audio API 现场合成，无音频文件
- 适配：桌面键鼠与触控；窗口缩放时重设画布与像素比（上限 2）
